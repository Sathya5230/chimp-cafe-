# chimp-cafe-

Wildly exceptional coffee & botanical canopy roastery web experience.

## Features
- **Cinematic Preloader**: Animated intro screen with custom typography and steam SVG animation.
- **Canopy Atmosphere Canvas**: Dynamic background particle animation simulating floating roasted beans and warm steam wisps.
- **Ambient Soundtrack**: Interactive rainforest and cafe audio ambiance with Web Audio API synthesis.
- **Interactive Menu**: Filterable menu with dietary tags and detail views.
- **Canopy Fortune Teller**: Interactive coffee fortune generator.
- **Responsive Design**: Designed with botanical aesthetics, glassmorphism, and responsive layouts.

## Tech Stack
- Vanilla HTML5 & CSS3
- Vanilla JavaScript
